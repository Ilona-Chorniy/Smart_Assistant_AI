# 🤖 Smart Assistant AI

**Smart Assistant AI** — інтелектуальний персональний AI-планувальник, створений на основі моделей штучного інтелекту.

Застосунок допомагає користувачам організовувати свій день, планувати завдання, визначати пріоритети та ефективно розподіляти час.

## ✨ Можливості проєкту

- 💬 Спілкування з AI-асистентом українською мовою.
- 🗓️ Допомога в плануванні дня.
- 📋 Організація завдань та визначення пріоритетів.
- ⏰ Рекомендації щодо ефективного розподілу часу.
- 🧠 Збереження контексту поточної розмови.
- 🔄 Можливість очищення історії чату.
- 🖥️ Вебінтерфейс на основі Gradio.
- 💻 Консольна версія асистента.

## 🛠️ Використані технології

- **Python** — основна мова програмування.
- **Groq API** — доступ до мовної моделі штучного інтелекту.
- **OpenAI Python SDK** — взаємодія з API через сумісний інтерфейс.
- **Gradio** — створення вебінтерфейсу.
- **python-dotenv** — безпечне завантаження API-ключа з файлу середовища.

## ⚙️ Встановлення та запуск

### 1. Клонування репозиторію

```bash
git clone https://github.com/Ilona-Chorniy/Smart_Assistant_AI.git
```

### 2. Перехід до папки проєкту

```bash
cd Smart_Assistant_AI
```

### 3. Створення віртуального середовища

```bash
python -m venv venv
```

Активація у Windows:

```bash
venv\Scripts\activate
```

### 4. Встановлення залежностей

```bash
pip install -r requirements.txt
```

### 5. Налаштування API-ключа

Створи файл `.env` у кореневій папці проєкту та додай:

```env
GROQ_API_KEY=твій_api_ключ
```

Отримати API-ключ можна на [Groq Console](https://console.groq.com/).

### 6. Запуск консольної версії

```bash
python app.py
```

### 7. Запуск вебверсії

```bash
python web_app.py
```

Після запуску вебінтерфейс буде доступний за адресою:

http://127.0.0.1:10000

## 💬 Команди консольного асистента

| Команда | Опис |
|---|---|
| `вихід` | Завершення роботи |
| `/reset` | Очищення історії розмови |
| `/time` | Відображення поточної дати та часу |
| `/help` | Перегляд доступних команд |
